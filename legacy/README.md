# legacy/ — 已停用的早期实现

这个目录里的代码**当前主程序不再加载**，保留仅作备查，不保证还能跑。

早期思路是「逐项下发」：把两套配置的灯效矩阵、RT 键程、按键行程、DKS、键位映射
一项一项写进键盘。这条路走通了，但有两个硬伤：

- 一次切换要下发 61 颗灯 + 72 键 RT + 72 键行程，耗时长；
- **DKS 写入后读回来恒为 0**，无法校验，不敢默认开启（怕写坏按键配置）。

后来发现键盘固件本身支持「板载配置槽位切换」，一条命令就能让整套配置（含灯效、
RT、行程、DKS、键位）一次性切换过去，又快又安全。于是改用
`kb_onboard.py`，本目录的代码就此退役。

| 文件 | 作用 |
| --- | --- |
| `atk_kb.py` | 逐项下发的协议实现（灯效 / RT / 行程 / DKS / 键位映射读写） |
| `atk_profile.py` | 从配置软件的本地数据库里解析出键盘配置（V8 序列化格式） |
| `export_profiles.py` | 把解析出的配置导出成 JSON |
| `test_shake.py` / `test_write.py` / `test_write2.py` | 当时验证写入正确性的临时脚本 |

> 目录内脚本依赖仓库根目录的 `hid_core.py`，已在文件顶部插入 `sys.path` 处理，
> 可以从任意位置运行。
